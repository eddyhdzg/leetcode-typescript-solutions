# 1464. Maximum Product Of Two Elements In An Array

### O(n log n) - TS with toSorted and slice

## Complexity

- Time: $$O(n \log n)$$
- Space: $$O(n)$$

## Submission

- Runtime: 0 ms · Beats 100.00%
- Memory: 57.17 MB · Beats 29.03%

## Code

```typescript
function maxProduct(nums: number[]): number {
  const [max1, max2] = nums.toSorted((a, b) => a - b).slice(-2);
  return (max1 - 1) * (max2 - 1);
}
```
