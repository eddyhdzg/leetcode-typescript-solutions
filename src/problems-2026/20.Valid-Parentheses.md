# 20. Valid Parentheses

### O(n) - TS with stack

## Complexity

- Time: $$O(n)$$
- Space: $$O(n)$$

## Submission

- Runtime: 3 ms · Beats 74.11%
- Memory: 57.14 MB · Beats 73.87%

## Code

```typescript
const PAIRS: Record<string, string> = { ")": "(", "}": "{", "]": "[" };

function isValid(s: string): boolean {
  const stack: string[] = [];
  for (const c of s) {
    if (c in PAIRS) {
      if (stack.pop() !== PAIRS[c]) return false;
    } else stack.push(c);
  }
  return stack.length === 0;
}
```
