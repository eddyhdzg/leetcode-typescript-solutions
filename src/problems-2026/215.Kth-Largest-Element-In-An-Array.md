# 215. Kth Largest Element in an Array

### O(n + k log n) - TS with MaxHeap

## Complexity

- Time: $$O(n + k \log n)$$
- Space: $$O(n)$$

## Submission

Runtime: 64 ms · Beats 59.17%
Memory: 66.88 MB · Beats 90.39%

## Code

```typescript
import { MaxHeap } from "@datastructures-js/heap";

function findKthLargest(nums: number[], k: number): number {
  const heap = MaxHeap.heapify([...nums]);

  for (let i = 1; i < k; i++) heap.pop();

  return heap.pop()!;
}
```
