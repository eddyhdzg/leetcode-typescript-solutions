# 2778. Sum Of Squares Of Special Elements

### O(n) - TS with divisor check loop

## Complexity

- Time: $$O(n)$$
- Space: $$O(1)$$

## Submission

- Runtime: 0 ms · Beats 100.00%
- Memory: 58.20 MB · Beats 52.38%

## Code

```typescript
function sumOfSquares(nums: number[]): number {
  const n = nums.length;
  let res = 0;

  for (let i = 1; i <= n; i++) {
    if (n % i === 0) res += nums[i - 1] ** 2;
  }

  return res;
}
```
