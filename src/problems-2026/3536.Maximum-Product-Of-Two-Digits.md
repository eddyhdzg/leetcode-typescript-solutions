# 3536. Maximum Product Of Two Digits

### TS with digit sort and slice

## Complexity

- Time: $$O(\log n \cdot \log \log n)$$
- Space: $$O(\log n)$$

## Submission

- Runtime: 1 ms · Beats 81.25%
- Memory: 57.64 MB · Beats 68.75%

## Code

```typescript
function maxProduct(n: number): number {
  const [a, b] = [...String(n)].toSorted().slice(-2).map(Number);
  return a * b;
}
```
