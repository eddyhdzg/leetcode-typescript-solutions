# 3550. Smallest Index With Digit Sum Equal To Index

### O(n) - TS with string spread and reduce

## Complexity

- Time: $$O(n)$$
- Space: $$O(1)$$

## Submission

- Runtime: 2 ms · Beats 40.91%
- Memory: 57.53 MB · Beats 81.82%

## Code

```typescript
function smallestIndex(nums: number[]): number {
  for (let i = 0; i < nums.length; i++) {
    const sum = [...String(nums[i])].reduce((acc, d) => acc + Number(d), 0);
    if (sum === i) return i;
  }
  return -1;
}
```
