# 3718. Smallest Missing Multiple of K

### O(n) - TS with Set() and linear scan

## Complexity

- Time: $$O(n)$$
- Space: $$O(n)$$

## Submission

- Runtime: 0 ms · Beats 100.00%
- Memory: 57.29 MB · Beats 80.00%

## Code

```typescript
function missingMultiple(nums: number[], k: number): number {
  const set = new Set(nums);
  let i = 1;
  while (set.has(i * k)) i++;
  return i * k;
}
```
