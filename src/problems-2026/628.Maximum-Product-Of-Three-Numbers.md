# 628. Maximum Product Of Three Numbers

### O(n log n) - TS with toSorted and reduce

## Complexity

- Time: $$O(n \log n)$$
- Space: $$O(n)$$

## Submission

- Runtime:  · Beats
- Memory:  · Beats

## Code

```typescript
function maximumProduct(nums: number[]): number {
  const sorted = nums.toSorted((a, b) => a - b);

  const last3 = sorted.slice(-3).reduce((acc, curr) => acc * curr);
  const first2AndLast = [...sorted.slice(0, 2), ...sorted.slice(-1)].reduce(
    (acc, curr) => acc * curr
  );

  return Math.max(last3, first2AndLast);
}
```
